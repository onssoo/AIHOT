# 使用规则

| 项 | 值 |
|---|---|
| 版本 | 1.0 |
| 生效日期 | 待站长确认后填写 |
| 运营主体 | 个人站点（站长本人）—— 待站长确认 |
| 联系方式 | 站内「反馈」页 |

页首说明：

> 本站聚合公开信源，用模型生成中文摘要与精选，原文版权归各来源所有。网站、RSS、公开 API 与 MCP 均可匿名使用。

## 1. 内容与版权

本站展示的标题、摘要和推荐理由由模型根据公开来源生成，**可能有误**。涉及学校日程、选课与考试安排、签证与身份、费用与奖助、交通与安全等信息，**请一律以学校官网和官方通知为准**。

原文版权归各来源所有；站内只在来源允许时展示全文，其余只展示摘要和原文链接。

## 2. 与学校及机构的关系

本站是**个人整理的信息聚合站，与 UBC（不列颠哥伦比亚大学）、澳门城市大学及其他任何学校、政府或机构均无隶属或合作关系**。站内出现的校名、机构名只用于标识信息来源。

## 3. 来源方的更正与下架

如果你是来源方，希望更正、下架或调整展示方式，请通过站内「反馈」页联系我们，我们会尽快处理。

## 4. 使用本站的数据

- **允许**：个人阅读、家庭内部使用、订阅 RSS。
- **需事先取得同意**：商业产品、公开转载、批量再分发、用于训练模型。

## 5. 接口与频率

RSS、公开 API 和 MCP 为匿名只读接口。请按响应中的缓存时间轮询，遇到 429 请遵守 `Retry-After`，不要并发重试；抓取请勿影响信源站点。

## 6. 免责

本站按「现状」提供，不保证内容完整、准确和持续可用。因依赖本站信息做出的决定，风险由使用者自行承担。
