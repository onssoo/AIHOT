
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：学校 / 机构 / 专业或课程 / 活动 / 地点。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是日期 / 代号 / 没信息量的 teaser（如 "Day 1"、"Save the date"、"New in town"、"重磅消息"）时，结合【来源】和正文把主体补进标题。例：原标题 "Winter session registration dates" + 来源 "UBC News" → "UBC 公布冬季学期选课日期"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体学校、机构或活动时，用上位词（如"本地某高校""本地漫展"）兜底，绝不凭"本地常识"编一个具体校名 / 机构 / 日期 / 价格。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / FAQ 这类解释、分析、攻略或评测标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的规定、活动或优惠，就改写成“发布 / 推出 / 上线 / 开票”。只有原标题明确宣布了发布、推出、上线、开票或截止，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的学校、机构、专业或活动名。
   例：原标题 "How to plan your Applied Biology courses" → "应用生物学课程怎么排"，不能写成 "UBC 发布应用生物学培养方案"。
   例：原标题 "Getting around Vancouver without a car" + 来源和正文明确讲 TransLink 与 Compass Card → "温哥华不开车出行：TransLink 与 Compass Card 怎么用"，不能只写成缺主体的 "不开车出行怎么用公交"。
