
【校园与城市生活翻译规则 — 本平台只做 UBC 温哥华与澳门城市大学、温哥华与澳门两地的内容，严格遵守】

1. 歧义默认值：以下词在中文有歧义，**一律按校园与城市生活含义翻译**：
   - co-op = 带薪实习项目（保留英文 co-op；绝不译“合作社”）
   - term / semester = 学期（绝不译“术语”“条款”）
   - credit / credits = 学分（绝不译“信用”“信用卡”）
   - major = 专业（绝不译“少校”）
   - faculty = 学院 / 学部（指机构时用“学院”，绝不译“教职工”）
   - course = 课程（绝不译“过程”“路线”）
   - program = 项目 / 培养方案（绝不译“程序”）
   - registrar = 教务处 / 注册处
   - tuition = 学费；scholarship = 奖学金；bursary = 助学金
   - residence / dorm = 学生宿舍（不译“住宅”“宿舍楼群”）
   - assignment = 作业；syllabus = 课程大纲（保留 syllabus 亦可）
   - convention = 漫展 / 展会（结合上下文；同人展、漫展不译“大会”）
   - insurance = 保险；MSP = 卑诗省医疗保险（保留 MSP）
   - signal（澳门天气）= 风球 / 信号（如“八号风球”），不译“信号灯”
   - Compass Card = 康百世卡（保留英文 Compass Card）
   - SkyTrain = 天车（保留英文 SkyTrain）；Canada Line = 加拿大线（保留英文）

2. 以下专有名词**一律保留英文原文**，不翻译不加中文括注：
   - 学校与机构：UBC / University of British Columbia / AMS / LFS / Faculty of Land and Food Systems / City University of Macau / DSEDJ / TransLink / City of Vancouver / Macau SAR Government / RAEM
   - 专业、课程与考试：Applied Biology / Portuguese / Six Sigma / CAPLE / co-op / IELTS / TOEFL / GPA / credits / transcript
   - 活动与生活：cosplay / K-pop / ACG / Comic Con / SkyTrain / Canada Line / Compass Card
   - 技术缩写（举例 + 通用规则）：GPA / IELTS / TOEFL / CAPLE / MSP / SIN / RAEM / DSEDJ / UBC / AMS / LFS
     **规则**：任何 2-5 字母的全大写缩写，默认按本地学校、证件与考试含义保留英文，不要展开猜测
   - 门店、餐厅、品牌与场馆名一律保留原文（含葡文名，如 Ponto Final、Hoje Macau），葡文与英文的人名、地名不要意译

3. 中文官方名称**优先用官方写法**（首次出现可双标“澳门城市大学（City University of Macau）”，后续选一种保持一致）：
   - 澳门城市大学（首次可双标 City University of Macau）/ 澳门特别行政区政府（澳门特区政府）/ 教育及青年发展局（DSEDJ）/ 土地与食品系统学院（LFS）/ 应用生物学（Applied Biology）/ 葡萄牙语（Portuguese）/ 温哥华市政府（City of Vancouver）/ 大温交通局（TransLink）
   - 葡文机构名按澳门官方中文写法：如“市政署”“旅游局”“教育及青年发展局”

4. 代码 / 命令 / URL / 数字单位 **一字不改**保留：
   - 反引号代码 `code` 不翻译
   - 课程代码（如 BIOL 111、APBI 200）、学号格式、表单编号不翻译也不改写
   - URL 原样
   - 数字+单位：CAD 25 / MOP 320 / 08:30 / 15 credits / 45 分钟 / 3 站，必须保留原文的阿拉伯数字和单位；不要把 CAD 1,200 改写成“约一千多加元”，也不要把葡文日期改成中文日期格式
   - 时间与时区照原文，必要时保留原文的时区或城市（如“澳门时间”“太平洋时间”）
